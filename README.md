# Rock Paper Scissors

A console-based Rock Paper Scissors game built with JavaScript as part of The Odin Project curriculum.

## Description

This is a simple implementation of the classic Rock Paper Scissors game where a human player competes against the computer over 5 rounds. The game runs entirely in the browser console with no graphical user interface.

## Features

- Play against computer opponent
- Best of 5 rounds gameplay
- Score tracking for both players
- Random computer choice generation
- Winner announcement after each round and final game results

## How to Play

1. Open `index.html` in your web browser
2. Open the browser's developer console (F12, CTRL + SHIFT + J, or right-click -> Inspect -> Console)
3. Follow the prompts to enter your choice (rock, paper, scissors)
4. The game will play 5 rounds automatically
5. Final scores and winner will be displayed at the end

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## Technologies Used

- HTML
- JavaScript

## Installation

1. Clone this repository
2. Open `index.html` in your web browser
3. Start playing!
